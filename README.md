# Calculator JS Project

A simple and responsive calculator built using HTML, CSS, and JavaScript.  
This project was created to improve my understanding of DOM manipulation, event handling, and JavaScript logic.

---

## Features

- Perform basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Percentage
- `AC` button to clear the screen
- `DEL` button to remove the last character
- Modern calculator UI
- Responsive layout

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

---

## Project Structure

```bash
Calculator-JS-Project/
│
├── index.html
├── style.css
└── script.js
```

---

## How It Works

- Buttons are selected using `querySelectorAll()`
- Click events are handled using `addEventListener()`
- User input is stored in a string
- `eval()` is used to evaluate the expression
- The result is displayed in the input box
